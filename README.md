# Saratoga Continentals FC

Official website for **Saratoga Continentals FC**, Saratoga, New York.

## Design direction

The site takes structural inspiration from leading football federation and club websites — strong club identity, match-first hierarchy, clear player-development pathways, news, teams and membership/tryout calls to action — while using an original Saratoga Continentals FC visual system.

## Stack

- Static HTML
- Modern responsive CSS
- Vanilla JavaScript
- No build step

This makes the site simple to deploy on Cloudflare Pages.

## Local preview

Open `index.html` in a browser, or run any static server from the repository root.

## Deployment

Recommended: **Cloudflare Pages** connected to this GitHub repository.

- Build command: leave blank
- Build output directory: `/`
- Production branch: `main`

Domain: `saratogacontinentalsfc.com`
